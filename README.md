## Selected projects

### Winsy — Personal work management & career evidence

An independent SaaS product concept for individual professionals. Winsy goes beyond task tracking: it helps people organise their work, keep a reliable record of what they deliver, and turn completed work into evidence of skills and achievements.

Current product work includes task and checklist workflows, a work log, evidence attachments and previews, rule-based achievement generation from recorded work, and reports with PDF/CSV export. The product is being shaped around a calm, focused, responsive experience, including PWA support.

**Focus:** Product design · UX/UI · React · TypeScript · Supabase · PostgreSQL · Data modelling · PWA

### PX Field — Workflow and quoting for flooring professionals

A vertical software product for independent tilers, flooring installers, and surface-installation businesses. The workflow connects customers and sites with projects, areas, measurements, installation specifications, labour quotations, schedules, and delivery.

I am shaping the product experience and its operational logic, including configurable business details, quote presentation, measurement calculations, and a product identity that stays separate from each business's own branding. The current repository is a front-end prototype, with persistence and integrations still on the roadmap.

**Focus:** Product strategy · Workflow design · UX/UI · React · TypeScript · TanStack Start · Tailwind CSS

### EURO — Digital presence for a tiling and flooring business

A responsive website for a real service business, designed to present services and projects and make quote requests straightforward. The implementation includes a project gallery, contact and WhatsApp pathways, and a quote-request flow backed by Supabase.

**Focus:** Brand and web design · React · TanStack Start · TypeScript · Tailwind CSS · Supabase · Cloudflare Workers

### Strato — Project cost management

A web application concept for organising construction project expenses, tracking categories and payment status, and reviewing costs through dashboards and reports.

**Focus:** UX/UI · React · TypeScript · Tailwind CSS · Supabase · Data visualisation
